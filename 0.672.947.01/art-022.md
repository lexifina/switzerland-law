# Art. 22 Vermögen

1. Unbewegliches Vermögen im Sinne des Artikels 6, das einer in einem Vertragsstaat ansässigen Person gehört und im anderen Vertragsstaat liegt, kann im anderen Vertragsstaat besteuert werden.

2. Bewegliches Vermögen, das Betriebsvermögen einer Betriebsstätte ist, die ein Unternehmen eines Vertragsstaats im anderen Vertragsstaat hat, oder das zu einer festen Einrichtung gehört, die einer in einem Vertragsstaat ansässigen Person für die Ausübung einer selbstständigen Arbeit im anderen Vertragsstaat zur Verfügung steht, kann im anderen Vertragsstaat besteuert werden.

3. Seeschiffe und Luftfahrzeuge, die im internationalen Verkehr durch eine in einem Vertragsstaat ansässige Person betrieben werden, und bewegliches Vermögen, das dem Betrieb dieser Schiffe oder Luftfahrzeuge dient, können nur in diesem Vertragsstaat besteuert werden.

4. Alle anderen Vermögensteile einer in einem Vertragsstaat ansässigen Person können nur in diesem Vertragsstaat besteuert werden.
