# Art. 1 Gebührenpflicht

1 Wer eine Verfügung einer Handelsregisterbehörde veranlasst oder von dieser eine Dienstleistung beansprucht, hat eine Gebühr zu bezahlen.

2 Haben mehrere Personen gemeinsam eine Verfügung veranlasst oder eine Dienstleistung beansprucht, so haften sie für die Gebühr solidarisch.
