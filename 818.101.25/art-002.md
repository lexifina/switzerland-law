# Art. 2 Aufbau

1 Das PT-System umfasst folgende Komponenten:

  - a. ein System zur Verwaltung von Annäherungsdaten (VA-System), bestehend aus einer Software, die von den teilnehmenden Personen auf ihren Mobiltelefonen installiert wird (SwissCovid-App), und einem Backend (VA-Backend);

  - b. ein System zur Verwaltung von Codes zur Freischaltung der Benachrichtigungen (Codeverwaltungssystem), bestehend aus einem webbasierten Frontend und einem Backend.

  - 2 Das VA-Backend und das Codeverwaltungssystem werden als zentrale Server vom Bundesamt für Gesundheit (BAG) betrieben.
