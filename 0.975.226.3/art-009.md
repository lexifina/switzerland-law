# Art. 9 Subrogation

(1) Hat eine Partei oder eine von ihr bezeichnete Stelle in Bezug auf eine Investition eines ihrer Investoren auf dem Hoheitsgebiet der anderen Partei eine Zahlung aufgrund einer finanziellen Garantie gegen nichtkommerzielle Risiken geleistet, so anerkennt die letztere Partei aufgrund des Subrogationsprinzips die Rechte der ersten Partei auf die Rechte des Investors.

(2) Hat eine Partei an einen ihrer Investoren eine Zahlung geleistet und ist dadurch in dessen Rechte eingetreten, so kann der Investor gestützt auf diese Rechte keinen Anspruch gegen die andere Partei geltend machen, ohne dass die erste Partei zustimmt.
