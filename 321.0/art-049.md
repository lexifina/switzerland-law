# Art. 49

1 Wird der Täter zu einer Freiheitsstrafe von mehr als drei Jahren verurteilt oder nach Artikel 64 des Strafgesetzbuches verwahrt, so ordnet das Gericht den Ausschluss aus der Armee an.

2 Wird der Täter zu einer anderen Strafe verurteilt, so kann das Gericht den Ausschluss aus der Armee anordnen.
