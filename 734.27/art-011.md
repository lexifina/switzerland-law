# Art. 11 Ersatzbewilligung

1 Beschäftigt ein Betrieb vorübergehend keine fachkundige Person, so kann ihm das Inspektorat eine Ersatzbewilligung erteilen, wenn er mindestens eine kontrollberechtigte Person oder eine Person beschäftigt, welche die Voraussetzungen für die Erteilung einer Bewilligung für Arbeiten an betriebseigenen Installationen (Art. 13) erfüllt. Diese Person ist in der Ersatzbewilligung aufzuführen.

2 Die Ersatzbewilligung ist sechs Monate gültig; sie kann um höchstens sechs Monate verlängert werden.

3 Solange der Betrieb eine Ersatzbewilligung besitzt, muss das Inspektorat dessen Installationstätigkeit besonders beaufsichtigen. Der Inhaber der Ersatzbewilligung trägt die Kosten.
