# Art. 19 Öffentliche Funktionen

Vergütungen, einschliesslich der Ruhegehälter, die von einem Vertragsstaat, einer seiner politischen Unterabteilungen, einer seiner lokalen Körperschaften oder von einer juristischen Person des öffentlichen Rechts dieses Vertragsstaates unmittelbar oder aus einem Sondervermögen an eine natürliche Person für erbrachte Dienste gewährt werden, können nur in diesem Staat besteuert werden. Jedoch können Vergütungen, ausgenommen Ruhegehälter, für Dienste, die in dem anderen Vertragsstaat von einem Staatsangehörigen dieses Staates erbracht werden, der nicht zugleich die Staatsangehörigkeit des erstgenannten Staates besitzt, nur in dem anderen Staat besteuert werden.
