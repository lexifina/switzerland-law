# Art. 35e Anzahl der Taggelder

1 Ist das Kind an mindestens vier Tagen hospitalisiert (Art. 16n EOG), ohne gesundheitlich schwer beeinträchtigt im Sinne von Artikel 16o EOG zu sein, so besteht für dieses Kind pro Tag nur für einen Elternteil Anspruch auf ein Taggeld.

2 Die Eltern können für dasselbe Kind nicht gleichzeitig eine Entschädigung für die Betreuung eines an mindestens vier Tagen hospitalisierten Kindes (Art. 16n EOG) und eine Entschädigung für die Betreuung eines im Sinne von Artikel 16o EOG gesundheitlich schwer beeinträchtigten Kindes beziehen.
