# Art. 14 Betriebszulage für Dienstleistende

Führt die anspruchsberechtigte Person einen Betrieb gemeinsam mit einer Person, die gestützt auf Artikel 8, 16fter, 16lter, 16rter oder 16wter EOG ebenfalls Anspruch auf die Betriebszulage hat, so wird für diesen Betrieb nur eine Zulage pro Tag ausgerichtet.
