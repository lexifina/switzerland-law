# Art. 8 Seeschifffahrt und Luftfahrt

1. Gewinne aus dem Betrieb von Schiffen im internationalen Verkehr können in dem Vertragsstaat besteuert werden, in dem das Unternehmen, das das Schiff betreibt, ansässig ist.

2. Solche Gewinne können jedoch auch in dem Vertragsstaat besteuert werden, in dem das Schiff betrieben wird; die dabei erhobene Steuer darf aber 50 Prozent der Steuer, die nach dem internen Recht dieses Staates sonst erhoben wird, nicht übersteigen.

3. Gewinne aus dem Betrieb von Luftfahrzeugen im internationalen Verkehr können nur in dem Vertragsstaat besteuert werden, in dem das Unternehmen, das das Luftfahrzeug betreibt, ansässig ist.

4. Die Absätze 1, 2 und 3 gelten auch für Gewinne aus der Beteiligung an einem Pool, einer Betriebsgemeinschaft oder einer internationalen Betriebsstelle.
