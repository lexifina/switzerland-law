# Art. 16 Beratungen

Jede Vertragspartei kann jederzeit Beratungen über die Durchführung, die Auslegung, die Anwendung oder die Änderung dieses Abkommens verlangen. Solche Beratungen, die zwischen den Luftfahrtbehörden stattfinden können, müssen innerhalb von 60 Tagen von dem Zeitpunkt an beginnen, an dem die andere Vertragspartei das schriftliche Gesuch erhalten hat, es sei denn, die Vertragsparteien haben etwas anderes vereinbart.
