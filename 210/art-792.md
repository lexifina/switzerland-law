# Art. 792

1 Wechselt das Grundstück den Eigentümer, so wird der Erwerber ohne weiteres Schuldner der Grundlast.

2 Wird das Grundstück geteilt, so werden die Eigentümer der Teilstücke Schuldner der Grundlast. Die Schuld wird nach den Bestimmungen über die Grundpfandverschreibung auf die Teilstücke verlegt.
