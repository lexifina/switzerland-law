# Art. 544

1 Das Kind ist vom Zeitpunkt der Empfängnis an unter dem Vorbehalt erbfähig, dass es lebendig geboren wird.

1bis Erfordert es die Wahrung seiner Interessen, so errichtet die Kindesschutzbehörde eine Beistandschaft.

2 Wird das Kind tot geboren, so fällt es für den Erbgang ausser Betracht.
