# Art. 13 Gewinne aus der Veräusserung von Vermögen

1. Gewinne, die eine in einem Vertragsstaat ansässige Person aus der Veräusserung unbeweglichen Vermögens im Sinne von Artikel 6 bezieht, das im anderen Vertragsstaat liegt, können im anderen Staat besteuert werden.

2. Gewinne aus der Veräusserung beweglichen Vermögens, das Betriebsvermögen einer Betriebsstätte ist, die ein Unternehmen eines Vertragsstaates im anderen Vertragsstaat hat, oder das zu einer festen Einrichtung gehört, die einer in einem Vertragsstaat ansässigen Person für die Ausübung einer selbstständigen Arbeit im anderen Vertragsstaat zur Verfügung steht, einschliesslich derartiger Gewinne, die bei der Veräusserung einer solchen Betriebsstätte (allein oder mit dem übrigen Unternehmen) oder einer solchen festen Einrichtung erzielt werden, können im anderen Staat besteuert werden.

3. Gewinne, die eine in einem Vertragsstaat ansässige Person aus der Veräusserung von Seeschiffen oder Luftfahrzeugen, die im internationalen Verkehr betrieben werden, oder von beweglichem Vermögen, das dem Betrieb dieser Schiffe oder Luftfahrzeuge dient, bezieht, können nur in diesem Staat besteuert werden.

4. Gewinne, die eine in einem Vertragsstaat ansässige Person aus der Veräusserung von Aktien, ausgenommen an einer anerkannten Börse gehandelte Aktien, bezieht, deren Wert zu mehr als 50 Prozent unmittelbar oder mittelbar auf unbeweglichem Vermögen nach Artikel 6 beruht, das im anderen Vertragsstaat liegt, können im anderen Staat besteuert werden.

5. Gewinne aus der Veräusserung des in den vorstehenden Absätzen dieses Artikels nicht genannten Vermögens können nur im Vertragsstaat besteuert werden, in dem der Veräusserer ansässig ist.
