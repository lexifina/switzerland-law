# Art. 21 Andere Einkünfte

Die in den vorstehenden Artikeln nicht ausdrücklich erwähnten Einkünfte einer in einem Vertragsstaat ansässigen Person können nur in diesem Staat besteuert werden; werden diese Einkünfte aber aus im anderen Vertragsstaat gelegenen Quellen bezogen, so können sie auch im anderen Staat besteuert werden.
