# Art. 8 Andere Verpflichtungen

(1) Sofern Bestimmungen in der Gesetzgebung einer Vertragspartei oder in internationalen Übereinkommen den Investitionen von Investoren der anderen Vertragspartei eine günstigere Behandlung zuerkennen als jene, die in diesem Abkommen vorgesehen ist, so gehen solche Bestimmungen, soweit sie günstiger sind, diesem Abkommen vor.

(2) Jede Vertragspartei erfüllt alle Verpflichtungen, die sie hinsichtlich Investitionen, die durch Investoren der anderen Vertragspartei auf ihrem Hoheitsgebiet getätigt wurden, eingegangen ist.
