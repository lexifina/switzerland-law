# Art. 76 Schwere Pflichtverletzung

1 Wer sich wiederholt schwerwiegende Disziplinarfehler zuschulden kommen lässt, wird mit Busse bestraft.

2 Verletzt die fehlbare Person ihre Pflichten während einer ausserordentlichen Zivildienstleistung schwer, so kann das Gericht eine Geldstrafe bis zu 90 Tagessätzen verhängen.
