# Art. 6

Dieses Abkommen kann von jeder Partei unter Einhaltung einer Frist von sechs Monaten zum Ende eines Kalenderjahres schriftlich gekündigt werden. In diesem Falle findet das Abkommen keine Anwendung mehr auf Pensionen, die ab dem 1. Januar des auf den Zeitpunkt der Kündigung folgenden Jahres gezahlt werden.
