# Art. 57 Einfuhr von Futtermitteln

1 Soweit die EU ein Verzeichnis der Länder führt, aus denen die Einfuhr von Futtermitteln zugelassen ist, so kann das WBF eine entsprechende Liste der Länder erlassen, aus denen Futtermittel, die die Voraussetzungen nach Artikel 7 oder 19 erfüllen, eingeführt werden können.

2 Das BLW kann besondere Bestimmungen für die Kontrolle von eingeführten Futtermitteln erlassen.
