# Art. 52 Übergangsbank

1 Die Übergangsbank dient der einstweiligen Fortführung einzelner, auf sie übertragener Bankdienstleistungen.

2 Die FINMA erteilt der Übergangsbank eine auf zwei Jahre befristete Bewilligung. Sie kann bei der Erteilung von den Bewilligungsvoraussetzungen abweichen. Die Bewilligung kann verlängert werden.
