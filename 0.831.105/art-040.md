# Art. 40

Hat eine geschützte Person auf Grund der innerstaatlichen Gesetzgebung im Falle des Todes des Ernährers Anspruch auf andere regelmässig wiederkehrende Leistungen als auf Leistungen an Hinterbliebene, so können diese regelmässig wiederkehrenden Leistungen für die Anwendung dieses Übereinkommens den Leistungen an Hinterbliebene gleichgestellt werden.
