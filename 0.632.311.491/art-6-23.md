# Art. 6.23 Weitere Verhandlungen

Gewährt eine Vertragspartei künftig einer Drittpartei günstigere Bedingungen beim Zugang zu ihrem Beschaffungsmarkt als in diesem Kapitel vorgesehen, so erklärt sie sich auf Ersuchen einer anderen Vertragspartei einverstanden, Verhandlungen mit dem Ziel aufzunehmen, den Geltungsbereich dieses Kapitels auf der Grundlage der Gegenseitigkeit auszudehnen.
