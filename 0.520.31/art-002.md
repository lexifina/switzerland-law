# Art. 2 Organisation der Kontrolle

Sobald eine Hohe Vertragspartei in einen bewaffneten Konflikt verwickelt wird, auf den Artikel 18 des Abkommens Anwendung findet,

  - a) ernennt sie einen Vertreter für das auf ihrem Hoheitsgebiet befindliche Kulturgut und, falls sie ein anderes Hoheitsgebiet besetzt hält, einen besonderen Vertreter für das dort befindliche Kulturgut;

  - b) ernennt die Schutzmacht jeder Partei, die sich mit dieser Hohen Vertragspartei in Konflikt befindet, bei der letzteren Delegierte gemäss Artikel 3 dieser Ausführungsbestimmungen;

  - c) wird bei dieser Hohen Vertragspartei gemäss Artikel 4 dieser Ausführungsbestimmungen ein Generalkommissär für Kulturgut ernannt.
