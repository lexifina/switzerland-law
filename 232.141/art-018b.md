# Art. 18b c. Nicht rechtzeitige Zahlung

1 Auf eine Anmeldung, für die eine fällige Jahresgebühr nicht rechtzeitig gezahlt worden ist, wird nicht eingetreten; ein Patent, für das eine fällige Jahresgebühr nicht rechtzeitig gezahlt worden ist, wird im Register gelöscht.

2 Das IGE löscht das Patent mit Wirkung vom Datum der Fälligkeit der nicht gezahlten Jahresgebühr; wird das Patent erst nach diesem Datum erteilt, so wird es mit Wirkung vom Erteilungsdatum gelöscht. Die Löschung wird dem Patentinhaber angezeigt.
