# Art. 28 Regionen im Sinne dieses Übereinkommens

1. Jede Vertragspartei kann dem Generalsekretär notifizieren, dass ihr Gebiet im Sinne dieses Übereinkommens in zwei oder mehrere Regionen aufgeteilt ist oder dass zwei oder mehrere ihrer Regionen eine einzige Region bilden.

2. Zwei oder mehrere Vertragsparteien können dem Generalsekretär notifizieren, dass sie aufgrund einer untereinander errichteten Zollunion eine einzige Region im Sinne dieses Übereinkommens bilden.

3. Jede aufgrund von Absatz 1 oder 2 erstattete Notifikation wird am 1. Januar des auf das Jahr der Notifizierung folgenden Jahres wirksam.
