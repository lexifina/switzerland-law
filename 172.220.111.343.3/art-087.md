# Art. 87 Anspruch

1 Die zusätzlichen Auslagen für die Haushaltführung werden pauschal abgegolten.

2 Die Pauschale wird nur einmal pro Haushalt entrichtet.

3 Macht die Begleitperson infolge ihres Anstellungsverhältnisses zum Bund einen eigenständigen Anspruch auf die Pauschale geltend, so wird diese auf der Grundlage des höheren der beiden Löhne berechnet.
