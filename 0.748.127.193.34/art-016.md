# Art. 16 Beratungen

Jede Vertragspartei kann jederzeit Beratungen über die Durchsetzung, die Auslegung, die Anwendung oder die Änderung dieses Abkommens verlangen. Solche Beratungen, die zwischen den Luftfahrtbehörden stattfinden können, müssen innerhalb von dreissig Tagen von dem Zeitpunkt an beginnen, an dem die andere Vertragspartei das schriftliche Gesuch erhalten hat, es sei denn, die Vertragsparteien hätten etwas anderes vereinbart.
