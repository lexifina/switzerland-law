# Art. 38

Jede Ufer-Regierung bestimmt ein für allemal das Obergericht, bei welchem die Berufungen gegen die in ihrem Gebiete von den Rheinschifffahrts-Gerichten erster Instanz gefällten Urteile angebracht werden können.

Das Obergericht muss seinen Sitz in einer Stadt haben, welche am Rheine oder doch nicht allzuweit von demselben gelegen ist.

Wird die Berufung bei diesem Gerichte eingelegt, so finden die für das Verfahren in Appellationssachen geltenden Landesgesetz Anwendung.
