# Art. 27 Eröffnung einer Untersuchung

1 Bestehen Anhaltspunkte für eine unzulässige Wettbewerbsbeschränkung, so eröffnet das Sekretariat im Einvernehmen mit einem Mitglied des Präsidiums eine Untersuchung. Eine Untersuchung wird in jedem Fall eröffnet, wenn das Sekretariat von der Wettbewerbskommission oder vom WBF damit beauftragt wird.

2 Die Wettbewerbskommission entscheidet, welche der eröffneten Untersuchungen vorrangig zu behandeln sind.
