# Art. 8 Schifffahrt und Luftfahrt

1. Einkünfte eines Unternehmens eines Vertragsstaates aus dem Betrieb von Schiffen oder Luftfahrzeugen im internationalen Verkehr können nur in diesem Vertragsstaat besteuert werden.

2. Absatz 1 dieses Artikels gilt auch für Einkünfte aus einer Beteiligung an einem Pool, an einer gemeinsamen Betriebsorganisation oder an einer internationalen Betriebskörperschaft.
