# Art. 29 Verfügung über die Befreiung von der Ersatzpflicht

1 Hat die Veranlagungsbehörde festzustellen, ob einem Ersatzpflichtigen ein das Ersatzjahr überdauernder Anspruch auf Befreiung von der Ersatzpflicht zusteht, so trifft sie eine besondere Verfügung.

2 Erwächst eine solche Verfügung in Rechtskraft, so bleibt sie gültig, solange keine neuen wesentlichen Tatsachen eintreten.
