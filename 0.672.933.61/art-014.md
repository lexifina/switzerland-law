# Art. 14 Selbständige Arbeit

1. Einkünfte, die eine in einem Vertragsstaat ansässige natürliche Person aus der Ausübung einer selbständigen Arbeit bezieht, können nur in diesem Staat besteuert werden, es sei denn, dass der natürlichen Person im anderen Vertragsstaat für die Ausübung ihrer Tätigkeit gewöhnlich eine feste Einrichtung zur Verfügung steht. Steht ihr eine solche feste Einrichtung zur Verfügung, kann der Teil der Einkünfte, die der festen Einrichtung zugerechnet werden können und die auf in diesem anderen Staat erbrachte Arbeit entfallen, auch in diesem anderen Staat besteuert werden.

2. Für die Ermittlung der Einkünfte, die nach Absatz 1 im anderen Vertragsstaat besteuert werden können, finden die Grundsätze von Artikel 7 (Unternehmensgewinne) Anwendung.
