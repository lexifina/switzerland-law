# 6. Übermittlung von klassifizierten Informationen

  - 6.1 In der Regel werden klassifizierte Information zwischen den Vertragsparteien auf offiziellen Kanälen weitergeleitet. Sofern jedoch von beiden Vertragsparteien akzeptiert, können auch andere Abmachungen, wie zum Beispiel persönliche Überbringung, sichere Datenübertragung (verschlüsselt), getroffen werden.
