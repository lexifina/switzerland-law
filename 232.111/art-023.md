# Art. 23 Mehrere Widersprüche, Aussetzung des Verfahrens

1 Sind gegen dieselbe Markeneintragung mehrere Widersprüche eingereicht worden, so bringt das IGE die Widersprüche allen Widersprechenden zur Kenntnis. Es kann die Behandlung der Widersprüche in einem Verfahren vereinigen.

2 Hält das IGE es für zweckmässig, so kann es zuerst einen von mehreren Widersprüchen behandeln und darüber entscheiden und die übrigen Widerspruchsverfahren aussetzen.

3 Stützt sich der Widerspruch auf eine Markenhinterlegung, so kann das IGE das Widerspruchsverfahren aussetzen, bis die Marke eingetragen ist.

4 Das IGE kann das Widerspruchsverfahren aussetzen, wenn der Entscheid über den Widerspruch vom Ausgang eines Verfahrens zur Löschung wegen Nichtgebrauchs, eines Zivilverfahrens oder eines anderen Verfahrens abhängt.
