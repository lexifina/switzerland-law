# Art. 8 Hinterlegung

1 Für die Hinterlegung muss ein vom IGE zugelassenes oder ein der Ausführungsordnung zum Markenrechtsvertrag von Singapur vom 27. März 2006 entsprechendes Formular verwendet werden.

2 Enthält eine im Übrigen formgültige Hinterlegung alle verlangten Angaben, so kann das IGE auf die Einreichung des Formulars verzichten.
